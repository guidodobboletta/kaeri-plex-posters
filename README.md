# Kaeri channel posters for Plex

Poster-shaped (2:3) versions of channel logos, for the programme tiles in Plex's Live TV "What's On" view. Plex crops wide logos to fill those tiles; these pad each logo onto a dark canvas instead.

The images are generated from the channel logos that Kaeri's own app displays. They're published here only because Plex apps load guide images from a public URL. The logos belong to their broadcasters.
